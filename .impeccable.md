## Design Context

### Users

Winderust is for the broad Windows audience, from everyday laptop users to
gamers and power users. It should make performance, power-plan, and process
control understandable without removing the depth experienced users need.

### Brand Personality

Calm, elegant, and sleek. The interface should feel trustworthy and controlled,
especially when exposing powerful system-level actions.

### Aesthetic Direction

Winderust has its own restrained Windows desktop identity rather than imitating
another application. Preserve its Bahnschrift typography, compact information
density, neutral surfaces, precise small-radius geometry, optional accent tint,
light and dark themes, and purposeful motion.

### Design Principles

- Make advanced Windows controls approachable to all users through clear labels,
  progressive disclosure, and conservative defaults.
- Keep the interface calm and operational: strong hierarchy, compact controls,
  restrained color, and no decorative visual noise.
- Preserve Winderust's established components, tokens, navigation structure, and
  interaction patterns instead of importing another product's visual language.
- Use motion only to clarify state and spatial relationships, and respect the
  existing animation preference.
- Adapt navigation and layout without hiding core functionality or changing the
  information architecture.
